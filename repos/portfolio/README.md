# Portfolio

Personal dev portfolio. Nuxt 4 + TypeScript + Tailwind + `@nuxt/content`.

## Develop

```bash
npm install
npm run dev
```

## Build (static)

```bash
npm run generate
```

## Content

Edit markdown in `content/projects/*.md` and `content/about.md`.
Site-wide config (name, socials, skills) is in `site.config.ts`.
