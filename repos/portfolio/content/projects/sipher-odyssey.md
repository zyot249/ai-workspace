## Overview

At **Atherlabs**, I worked as a backend software engineer on a **five-person team** building the services behind Sipher Odyssey, an online roguelike game incorporating NFT-based item trading.

The system uses a microservices architecture to manage game data and logic, with REST APIs, gRPC, SignalR, and Kafka supporting communication.

## My contributions

- Developed service codebases within the microservices architecture.
- Owned matchmaking implementation using OpenMatch.
- Implemented battle and in-game item features, achieving over **80% unit test coverage** for that work and providing comprehensive documentation.
- Collaborated with DevOps on canary deployments to minimize downtime.
- Monitored, load-tested, and improved system performance to handle up to **5,000 requests per second**.
- Reviewed teammates' technical solutions and code.

## Engineering focus

This work combined service development with production readiness: testing gameplay features, coordinating deployments, and using observability to guide performance improvements.
