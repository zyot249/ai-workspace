## Overview

At **Zingplay Game Studio**, I worked as a game server engineer on a **two-person team** supporting Lucky 9 in the Philippines. The server manages data and gameplay logic for a card game in which players aim to reach a count of nine.

## My contributions

- Developed game events capable of supporting **1,000 concurrent users**.
- Built an administration tool for live operations and internal game-state controls.
- Collected and processed up to **5 GB of game logs per day**.
- Visualized gameplay metrics to support decisions by the business team and game designers.

## Technology

The game server uses Java, the in-house Bitzero framework, and WebSocket communication. Administration and metrics tooling uses PHP, HTML, and CSS, with Python, Spark, and Hadoop supporting data processing.
