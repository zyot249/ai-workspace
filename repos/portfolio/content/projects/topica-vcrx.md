## Overview

At **Topica Education**, I worked as a backend software engineer on a **three-person team** building Topica VCRX, a video conferencing application for online classes based on Jitsi Meet.

## My contributions

- Collaborated with the team leader to migrate the codebase to a new version with updated organizational rules and coding standards.
- Investigated and implemented client-side unit testing with Jest.
- Developed single sign-on functionality to streamline access across web and mobile applications.

## Technology

The backend uses Java, Spring Boot, and MongoDB. The web and mobile clients use React, React Native, and Jitsi Meet.
