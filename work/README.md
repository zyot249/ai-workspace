# work

Agent working sessions, organized by topic and date.

## Convention

Each session gets its own folder, named `YYYY-MM-DD-topic-name`:

```
work/
  <YYYY-MM-DD-topic-name>/
    research/    # research results, notes, findings
    plan/        # implementation plans
    handoff/     # current state, decisions made, next steps
```

Files inside each subfolder also carry a `YYYY-MM-DD-topic-name.md` name — split into multiple files when a single doc gets unwieldy (e.g. `research/2026-09-21-api-options.md`, `research/2026-09-22-prior-art.md`).

Not every task needs a `work/` entry — reach for one when a task spans multiple sessions or needs a handoff between agents/sessions.
